# 🧮 Django Advanced Calculator

A simple yet powerful web-based calculator built with **Django**.  
Supports arithmetic operations (+, -, ×, ÷, %, and exponents) with a clean, responsive UI.

---

## 🚀 Features
- Perform addition, subtraction, multiplication, division, modulus, and exponentiation.
- Handles invalid input and division-by-zero gracefully.
- Built using Django’s templating system.
- Clean and modern HTML/CSS interface.
